# TeacherCourseQuery - 课程表查询与导出工具

## 项目简介

TeacherCourseQuery 是一个基于 Python 的课程表查询与导出工具。该项目内置了 36 个班级的完整课程数据，支持通过命令行交互菜单查询和导出格式化的 HTML 课表文件。

## 功能特性

- **全部班级导出**：一键导出所有 36 个班级的课程表，按年级分标签页展示
- **单个班级查询**：选择特定班级，生成该班级的详细课程表
- **教师课表查询**：按教师姓名查询，显示该教师的所有授课安排及所授班级列表
- **HTML 输出**：生成带 CSS 样式的精美 HTML 文件，支持打印优化
- **自动打开**：生成后自动在浏览器中打开课表文件

## 快速开始

### 环境要求

- Python 3.6+
- 无需安装第三方依赖（仅使用 Python 标准库）

### 运行方式

```bash
python main.py
```

### 使用说明

运行后进入交互式菜单：

1. **Экспорт всех классов** - 导出全部班级课表
2. **Экспорт одного класса** - 导出单个班级课表
3. **查询 преподавателя** - 查询教师课表
4. **Выход** - 退出程序
